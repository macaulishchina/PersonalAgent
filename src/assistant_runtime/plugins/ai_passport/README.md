# FoloToy AI Passport

本目录包含 PA 扩展插件和独立构建的 `firmware/` ESP-IDF 工程。两端同仓库维护，
不创建第二套助手、模型调用或执行循环。

## 当前范围

- 插件已有静态声明、空配置描述和生命周期入口，仅使用公共 `assistant_runtime.api`。
- PA 端尚未实现设备发现、BLE、Wi-Fi、配对、协议、显示、按键、音频或任何模型工具。
- slim、standard 和现有实例均不默认启用。没有新增 Python 依赖或后台工作。
- 显式将 `ai_passport` 加入实例 `plugins` 后报告 `degraded` 与
  `ai_passport_scaffold_only`，不会把占位状态显示为设备就绪。
- 目前只声明 Linux 占位生命周期；Windows 和真实设备接入尚待分别验收。
- 没有业务配置项，不提前加入端点、凭据或传输方式。后续配置由本插件维护。

## 目录与发布

`declaration.py` 负责声明，`plugin.py` 负责生命周期，`docs/` 记录两端边界。
`firmware/` 独立编译，不由 PA 加载、编译或刷写。Python wheel 交付插件描述与
文档，排除固件、工具链及构建产物；固件开发使用本仓库源码。

固件工程提供独立 PPDemo 硬件体验／质检应用，未接入 PA；构建及真机验收状态单独记录。板级约束、上游
提交和许可证见[固件工程](firmware/README.md)。插件、固件、未来线协议分别管理
版本；现在不声明虚构协议或兼容设备版本。

后续按实际功能声明公共能力、资源和依赖；通过 PA 现有模块处理对话、执行、
用量、任务、通知与取消，不直接访问宿主。连接或重启不得重放未知操作；语音仍需
独立验收，不改变固定 USB 主输入输出绑定。见[两端边界](docs/protocol.md)。
