# 终端协议 2 与模块边界

协议 2 的服务端与固件正在本次重构验收中；0.2.0 开发固件已刷入 Dell 上的 PP
并完成首次启动检查，尚非完整硬件验收。不能与协议 1 固件混用，PA 生产服务尚未切换。
开发清单见 [terminal-rebuild.md](terminal-rebuild.md)。

## 所有权

| 模块 | 所有权 |
|---|---|
| conversation | 独立会话、输入收据、澄清与引导原子检查、历史游标及会话图片授权 |
| Pi | 唯一执行循环、工具、取消及供应商明确的消息阶段证据 |
| speech_io | 有界开流缓冲、序号、音频量、输入结束及流清理 |
| aliyun_speech | 阿里协议、字数／秒数的预留结算、音色与语速 |
| notifications | 任务通知及终端收到／播放／已读收据 |
| ai_passport | 设备身份、连接、配置版本、分句播报与播放收据 |
| app + configuration entrance | 私有控制通道、管理员管理及公共 HTTP/WS 入口 |
| firmware | 按键、固定预算Flash缓存、显示、PCM、Wi-Fi、NVS 与休眠 |

插件只通过 PluginContext 访问已声明能力。会话由服务端绑定，设备不能提交任意
session_id、模型、供应商密钥、执行身份、文件路径或外部图片 URL。

## 地址与数字配对

PA 业务根地址例如 `http://服务器:8047`，对应：

- POST `/entrances/ai_passport/pair`
- WebSocket `/entrances/ai_passport/stream`

9443 固件网站不承载业务。HTTP 不等待 NTP 或检查证书；显式使用 HTTPS 时须正常
校验证书和服务器名称，私有 CA 通过初次热点配置或已配对设备的云端配置提供。

设备随机生成并持久保存自己的 ID 和凭据；POST 内容仅为
`{protocol:2,device_id,credential}`。未配对返回八位十进制码及到期时间，码十分钟有效。
操作者在 PA 后台输入该码，服务端消费码并绑定独立会话；设备再次查询得到 paired。
重复查询不能延长现有配对码寿命；确认丢失可以核实已配对身份，不创建第二个会话。

WebSocket 使用 Authorization Bearer 与 X-Device-Id，拒绝 Cookie、Origin 和重复活动
连接。撤销立即断开设备，已经接受的业务继续。配对材料和供应商密钥不下发到浏览器。

## 有界消息与历史

每条 JSON 不超过 16 KiB；索引不拉取完整正文或工具日志。

| 上行 | 下行与约束 |
|---|---|
| input.begin(request_id, mode) | input.ready(request_id, max_audio_bytes)；先绑定目标及共享工作额度，再接受序号音频 |
| 二进制：4 字节大端序号 + PCM16 | 16kHz 单声道，缺帧／超量／开流缓冲溢出明确失败 |
| input.finish(request_id, frames, confirmation_required) | recognizing、transcript、input.receipt；超限等待确认 |
| input.confirm(request_id) | 仅提交服务端保存的待确认转写，重复请求查持久收据 |
| input.transcript(request_id, offset) | 仅待确认输入可读，每页 80 字、全文长度及下一偏移；不能读取其他设备或已提交输入 |
| input.cancel / input.receipt | 取消未提交输入或查询收据，不重发未知业务 |
| history.index(before/after, limit) | 会话范围内的双向游标，每条含自身游标；最多 20 条 80 字预览，设备使用 3 条窗口 |
| message.page(message_id, offset) | 80 字正文页、作者、全文长度、next_offset/null、修订时间及图片引用 |
| image.open(message_id, image_id, width?, height?) | 已登记且属于此消息的缩略图，最多 160×96，RGB565 小端，SHA-256 版本；设备按内存余量请求更小尺寸 |
| image.chunk(version, offset) | 最多 2048 字节像素的 Base64，明确下一偏移；版本不符拒绝 |
| image.close | 释放服务端当前缩略图；每个连接最多保留一张，不保存原图到 PP |
| playback.stop | 结束本条播报；不提供继续、恢复或重播操作 |
| playback.credit(generation, bytes) | 播放窗口最多 8192 字节；二进制为 4 字节大端播放版本 + PCM16 |
| playback.completed(generation) | 设备完整消费本句 PCM 后确认；不等于业务执行结束 |
| execution.cancel(request_id) | 使用现有会话取消机制，停止播报不代替取消执行 |
| notifications.list(before) | 有归属的任务结果、小页及游标；离线积压不连续补播 |
| notification.page(id, revision, offset) | 返回同一通知的id、revision、offset、text及next_offset；不使用语音内部消息id |
| notification.receipt | received、played、read 独立收据 |
| configuration.reload | 获取已应用的文件配置，不读取未保存的后台草稿 |
| configuration.applied(versions, actual) | 持久应用的字段版本；只回显音量、输入模式、保持在线等无敏感本地偏好 |

重连补齐的`message`事件带可选`restored=true`，仅恢复本地索引/页面，不触发新回复提示或
旧声音重播。设备导航是显示状态，不是执行状态；返回主页不取消已接受工作，菜单及任务页
不被迟到正文、正文读取响应或播放事件抢占。待澄清问题保持独立的有界显示缓冲，返回主页
后仍可上下查看并回答；问题归属及回答接受继续由会话服务管理。

图片来自现有文件资源设施。会话先核对消息及图片归属，再生成缩略图；没有 URL
下载代理，也不因图片显示失败重新执行截图等工具。图片工具正文不作为聊天正文显示。

设备RAM仅持有有限目录和当前显示页，正文及预览由统一Flash缓存层读取；
向前后继续浏览通过受限游标读取，不累计整个会话。返回的旧页只能匹配当前读取身份与偏移，
不会覆盖已切换的页面。每次只接收一张缩略图，校验完整像素、分块顺序和 SHA-256 后显示；
显示完成释放服务端缩略图，离开图片时先解除 LVGL 引用再释放设备缓冲。

## 流式文字、分句播报及取消

文字沿用已提交的会话增量。消息阶段保存在公共 `presentation.text_ranges` 中，以 Unicode
字符偏移关联正文；Pi 协议字段仅在 Pi 适配层解析，不放进模型上下文或工具参数。

- 提供 `final_answer` 的供应商：完整确定句可以在消息结束前播报。
- `commentary`、思考块、未确定的阶段：不会提前朗读。
- 不提供阶段的供应商：正常完成、确认最终回复后开始播报，不根据文案猜测。
- 阶段冲突、正文被替换、失败／取消／结果未知：撤销后续可播范围，保留实际文字与业务证据。
- 简短模式约 200 字，只播完整句；完整模式持续分页分句；关闭模式不合成。
- 单句超过当前有界段且无句界时提示看文字，不截半句冒充播完。

每句 `playback.start` 携带播放版本及源偏移，接收窗口有界；`playback.end` 只表示服务端
下发完，设备消费后回 `playback.completed` 才开始下一句。`playback.finished` 表示本条自动
播报结束，reason 区分完整、简短上限、需要查看文字。按下 OK 后提升播放版本、清空
待播内容和设备缓冲，后续文字继续显示；同一消息后续增量不能复活已停止的播报。

播放收据复用私有仓库，记录 played、stopped、unavailable 或未知。重连不重播历史音频。
会话增量使用持久事件游标；公共事件只作唤醒，丢唤醒时三十秒恢复核对，不高频扫描数据库。
ASR 转写使用独立更新信号；仅最终转写能进入会话。

## 配置版本与恢复

文件是唯一目标配置来源。`ai_passport.devices.<device_id>` 为设备覆盖值，未填写字段使用
插件默认设置。Wi-Fi 用优先级 1—5 的命名表配置，线上转换为有序列表。
`brightness` 为40—100的背光值，默认65；`text_size` 为16或18，只作用于正文。
两档原生字库存放在Flash，设备按真实行高重新分页，不占用额外整屏图层。

下发 `configuration.fields.<field>={version,value}`。只有实际目标值变化才产生新版本；
重连和设备菜单“重载配置”不会重置没有远程修改的本地偏好。移除原网络覆盖时下发 null
解除云端管理，不删除设备最后可用的网络。设备只在安全空闲点持久应用网络变更，
保存成功后才确认版本。服务端只保存派生版本、值指纹与非敏感回执，不存第二份目标配置。

断线不取消服务器已接受任务。输入 ID 写入 NVS，恢复只查收据，未知操作不换 ID 重做。
超限输入先由会话模块持久保存完整转写，再通知设备进入 `review`，尚不进入模型、任务或记忆。
设备只缓存当前文字页；确认菜单默认“丢弃”，另可明确发送或查看全文，查看后返回仍默认丢弃。
断线或重启恢复 `review` 时继续等待明确选择；确认只使用保存的原文，不接受替换正文。
发送确认丢失后查询同一输入收据，不重新识别或创建新输入。明确丢弃清除待确认正文，
确认接受后正文沿用原会话存储，不在待确认记录保留第二份。
ASR 失败不进入执行；TTS 失败保留文字和业务结果；计量失败阻止付费调用，不影响只读历史。
原始音频只在有界内存中，默认不落盘、不进入普通日志。

任务页读取仅锁定一个有界只读请求，不锁住导航。改变列表选择或返回即丢弃本地读取等待；
迟到页按通知ID、修订和偏移核对。格式错误、明确失败或15秒读取期限到期后可再次选择；
没有自动重试，也不因读取失败重做后台任务。只有匹配且内容有效的页面才标记已读。

收音同时受时间和实际PCM字节数限制。服务端input.ready给出实际max_audio_bytes，
设备取自身60秒上限与该值的较小者；16kHz单声道PCM16的60秒为1,920,000字节，
640字节帧最多3000帧。任一上限先到即停止，达到字节上限后仅丢弃界限外的本地尾帧，
已发送的帧保持原序号和完整性，完成转写后仍须明确确认；不能为接受越限流而放宽服务端校验。

服务端区分speech_input_gap、speech_invalid_pcm、speech_input_limit及speech_input_deadline。
错误关联已绑定设备的输入ID；关闭后的残留PCM不再刷出一串新错误，取消和收据仍使用
原持久输入记录。新输入必须重新prepare并取得自己的额度，未知ID不能沿用失败输入权限。
日志只记阶段、序号、字节和上限等元数据，不记录PCM或识别正文。

设备凭据和会话绑定持久化，普通服务/设备重启不重新配对；八位码只用于首次绑定。
同一设备验证成功的新连接接管旧传输，旧连接关闭不会取消已接受工作，也不能移除
替代连接的登记。错误凭据和已撤销凭据不能接管，其他设备仍受连接数量上限限制。
入口代理两端均使用WebSocket心跳，避免设备重启后的旧TCP占位永久在线。

## 持久聊天缓存（协议2的可选数据能力）

终端使用固定512 KiB的独立LittleFS分区；对象占用预算256 KiB（按4 KiB Flash块保守计算）、最多128个对象，
其中为缩略图保留32 KiB，
为原子替换、文件系统元数据和回收保留空间。缓存是可丢弃的副本，不保存执行状态、
供应商密钥、PCM或播报音频，不改变服务端会话和工具回执。

- 服务端在握手、完成消息及事件恢复时推送`cache.index`，最多3条已完成消息，按会话顺序。
  用户输入与助手回复分别算一条；带图的工具结果仍是独立历史项。它独立于在线浏览游标，
  也不前移消息事件游标。流式临时内容只显示，不作为已完成离线正文。
- 数据层在空闲时轮流读取这三条的正文，先保证每条开头确认写入，再向后补齐；一次目录版本最多
  预取96页，每页80字符。反复连接优先命中已有页，不反复下载。达到预取/空间上限后，
  更长内容仍可在线按需读；未缓存的后段明确提示，不冒充全文，也不无限预取。
- `message.page`的可选布尔`prefetch`仅标记这条只读请求的用途；会话身份和权限检查不变。
  后台预取失败返回`cache.prefetch_unavailable`，不使前台回答失败、不触发执行或模型重试。
- 固件业务调用统一走正文读取接口，按当前目录中的消息ID、修订和偏移命中Flash，
  缺失/损坏时仅在在线状态回源。正在浏览的旧目录不能修改最近窗口；旧版本不能满足新版本。
- 浏览已接收的图片后缓存一个保持比例的RGB565小预览，最大64×32，先验证来源完整性，
  再原地缩小并重算摘要；关闭显示后移交像素缓冲，不复制整张图片。启用图片显示时空闲预取每条最近消息
  的第一张预览；其他图片按实际查看缓存。线上传输继续按可用内存自适应尺寸。
  缓存读回仍检查长度、尺寸、CRC及像素摘要，不缓存原图，不把元数据当作已有图片。
- 断线时，历史浏览转入独立的最近缓存窗口；主页上下键也从该窗口进入。
  重启/休眠后保留已提交的正文、目录和预览。离线请求只查缓存，缺页/边界明确提示，
  缺失的整条可跳过；恢复联网后不抢走当前正在读的页面，不重播旧声音。
- 最近三条当前修订的对象受保护，浏览其他记录不能挤掉它们；其余按写入顺序回收。
  相同内容不重复写Flash，读取不刷写访问时间。空间不足或队列忙时放弃缓存写入，
  不能拖垮聊天。关闭`offline_cache`后停止读写，已有物理数据不等于被安全擦除。
- 所有文件访问归一个有界低优先级I/O任务；UI/按键/音频回调不做文件I/O。
  收音和播报期间停止新缓存写入，预取只在前台空闲时进行。图片分配仍保留20,000字节
  系统余量；内存不足时降低尺寸或明确不可用，不为缓存降低余量。
- 缓存空间按服务器地址、设备及绑定会话散列隔离。切换绑定时使旧在途读取失效。
  每个对象带版本、长度和CRC；同目录临时文件写完同步后通过LittleFS原子替换。
  启动丢弃未提交临时文件。挂载损坏时最多重建一次这个明确的可丢弃分区，绝不清NVS、
  配对、固件、任务或云端资料。部分预取中断保留上一份已提交目录。

本次引入固定`joltwallet/littlefs==1.22.3`，通过组件锁文件复现。
参见[组件源码](https://github.com/joltwallet/esp_littlefs)及
[LittleFS设计](https://github.com/littlefs-project/littlefs#readme)。
PA-Terminal独立分区表保留NVS/PHY及应用起始地址，factory结束于0x780000，
缓存占0x780000—0x800000。PPDemo布局保持原样。更新需要刷入新分区表和应用；
发布包不携带缓存镜像或NVS，不擦除配对数据。不要用旧应用最大尺寸覆盖新增缓存分区。
