## 已确认决策

- PP 8047 HTTP/WS；9443只用于固件网站。使用现有公共入口，不另开Agent。
- 独立持久会话、主对话模型、可选共享记忆、既有任务/通知所有权与用量。
- 长按说话，松开即停；短按永久结束本条播报，无继续听；双击引导/排队持久保存。
- 播报时上下调音量，其余直接上下浏览时间线；没有独立历史目录。
- 文字流式；完整确定句可提前播报；简短/完整/关闭，所有音频有界。
- 猫待机/缩小上移输入，简洁状态栏/页脚，正文分页完整；回复及历史无猫。
- 图片用有权访问的服务端缩略图，不下载原图或任意URL；历史在线分页+RAM有限缓存。
- 热点配网，8位单次码后台绑定，无USB配对文件；最多5套Wi-Fi顺序连接最多3轮。
- 云控字段版本，只覆盖后台改过的对应项；本地音量/模式/保持在线持久保存。
- 默认两分钟休眠，无插电检测；录音超限停收音、保留转写、默认丢弃、确认才发。
- 不做唤醒、全双工、蓝牙联网、OTA、多会话选型；不更换固定USB音频路线。
