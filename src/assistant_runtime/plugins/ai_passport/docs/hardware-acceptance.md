# PA-Terminal 集中真机验收

先完成本轮全部功能、软件回归、固定工具链构建和本地打包，再选定一份应用 SHA256。
同一轮测试使用同一份固件；发现阻断问题时修复并重新确认受影响项，不混合不同版本宣称通过。
验收期间不替换生产 PA，不操作真实媒体或家庭设备。USB 用于刷写和只读串口诊断。

## 准备

- PP 连接 Dell；串口有当前用户读写权限。临时 ACL 在重新枚举后可能失效。
- 记录固件版本、协议、应用摘要、PA 源码版本和测试环境；刷写仅覆盖应用区，保留 NVS。
- 使用隔离实例、合成模型和合成图片。保留指定设备及同一会话，不能复制生产 OAuth 或更换根目录来绕过额度。
- 先检查软件门禁与包内镜像摘要，再集中刷写。首次新配网才使用屏幕热点；已有协议2设置不清除。
- 正式8047仍是HTTP/WS业务入口；隔离验收临时使用18047，9443只属于固件网站。

`scripts/check_passport_hardware.py` 提供真实PA／Pi执行、数字配对和WebSocket桥接。
默认仅占位识别与合成提示音，不产生供应商费用。`--image-fixture` 在首次输入中由Pi读取
合成色卡，`--task-fixture` 随后创建一次隔离后台任务。程序只接受指定的设备ID。
`--resume` 只恢复自己的标记实例；模型模拟端点、设备、会话和执行证据保留，旧输入不重放。

真实语音仅在显式传入以下三项时启用：

- `--real-speech-key-file`：含DASHSCOPE_API_KEY的私有.env。
- `--speech-ledger`：原累计验收账本目录，不能新建替代账本。
- `--other-speech-ledger`：生产语音调用所在的既有usage.sqlite3。

它仍使用合成模型。语音准入复用原账本及用量服务，每次派发重新扣除另一账本的占用，
已提交和未知预留均计入原10元上限；额度不足即停止，不重试、不清空预留。
价格是保守测试估算，不能当作供应商账单。程序默认不保存原始音频。

## 一次集中体验检查

| 顺序 | 操作 | 验收依据 |
| --- | --- | --- |
| 1 | 冷启动、已有Wi-Fi及配对恢复 | 原设备、原会话；状态可理解，无旧声音或旧任务重放 |
| 2 | 短按、双击、长按说短句后释放 | 短按／双击不提交ASR；起始不丢字；释放立即停收音；模式持久化 |
| 2a | 双击、无声输入、任意页长按上 | 双击不闪收音；空输入仅形象和一句提示；长按上回主页且释放不额外翻页；任务继续 |
| 3 | 中文、数字、否定、改口、设备／影视名、中英混说 | 对照主动说出的样本和最终转写，不读取旧录音；失败不提交残缺指令 |
| 4 | 输入很长、达到60秒、分别丢弃与确认 | 整行滚动；默认丢弃；全文可分页；明确确认前没有模型执行 |
| 5 | 流式回复及准备／播放时按上下、短按OK | 已确认句才能出声；音量数值／进度条清晰；停播后永不恢复该条声音，文字继续 |
| 6 | 处理期间补充、切换排队、等待澄清后回答、取消 | 归属正确；收据去重；已接受任务不随设备断线被重做 |
| 7 | 上下翻多段历史、离线查看、再上线 | 当前正文到边界再换消息；断线转最近3条；旧历史浏览不挤掉它们；文字/预览断电后保留，缺页明确提示 |
| 8 | 查看合成色卡、前后翻页、内存压力时降尺寸 | 颜色与完整性正确；一次一张缩略图；无原图或整段历史常驻 |
| 9 | 隔离后台任务完成、离线结果、任务消息菜单 | 仅本PP会话；前台答复与后台通知不重复；未读/已收/播完区分；积压不连播 |
| 9a | 任务详情OK返回、列表返回菜单、三级菜单 | 蓝色任务标记与聊天区分；明确退出；各层最多5项，低频操作在维护子菜单 |
| 10 | 后台改亮度、字号、播报策略及多Wi-Fi，设备重载 | 改过的字段生效并确认版本；未改字段保留本地音量/模式/保持在线 |
| 11 | 断网、服务重启、最多三轮Wi-Fi耗尽后显式重试 | 原会话恢复；未知结果不重发；状态及错误明确 |
| 12 | 手动休眠、默认两分钟空闲休眠、按键唤醒 | 活动交互不自动睡；唤醒等待释放；后台继续且旧声音不重播 |
| 13 | 撤销配对、重新绑定、重新配网和出厂确认 | 撤销后拒绝业务；默认取消破坏性菜单；不删除PA记录或其他设备设置 |

切换测试模式、重启隔离服务前，先通过管理接口核对活动工作并正常收尾。后台静默策略用
隔离实例配置验证，不修改生产夜间策略。软件故障注入通过不替代上述按键、声学与显示证据。

## 100次交互与两小时稳定性

固定同一候选，累计至少100次真实PP输入／交互。可分为短句、长句、播放打断、历史／图片、
后台结果与恢复等小批次；记录实际完成次数、请求ID、失败类别及是否重复派发。
合成协议客户端的循环另计，不能充当物理按键或实际扬声器测试。

稳定性至少通电运行两小时，覆盖TLS（如实际采用）、Wi-Fi、音频、显示同时工作。
使用只读`pp.status`与现有分钟内存日志记录可用堆、最低堆、最大连续块及重连次数；
正确设置原生USB的DTR/RTS，避免诊断工具复位设备。记录panic、看门狗、内存分配失败、
音频队列溢出、持续下降及串口诊断造成的复位，不能把后者归咎于固件。

按键到收音、释放到最终转写、会话接受到首字、可播句到真实出声、OK到真实静音分段计时。
目标为按键／停播约200ms，稳定网络样本的转写与首声争取P95≤1.5s；样本不足不计算P95。
不把响应头、提示动画或服务器收到PCM当作实际出声时间。

丢音、误派发、重复动作、身份越界、死锁或持续泄漏阻断交付。最终分别报告软件、
真实供应商及真机结果，保留未通过与未测项；全部通过后才安排生产启用和正式上架。
