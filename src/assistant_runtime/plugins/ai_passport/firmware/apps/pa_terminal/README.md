# PA-Terminal

AI Passport 的 PA 交互入口。代码与构建已经接通协议 2；真机验收状态以
[交付清单](../../../docs/terminal-rebuild.md)及[验收记录](../../../docs/acceptance.md)为准。
开发时先看 [PP 开发架构](../../../docs/architecture.md)。PPDemo／PPDemo-Zh 是独立的硬件体验程序。

## 安装与首次使用

1. 使用现有固件网站安装 PA-Terminal。网页 USB 刷写要求可信 HTTPS；这不表示
   PP 的业务连接也必须使用 HTTPS。使用数据线，选择 USB JTAG/serial 设备。
2. 首次开机未配置网络时，屏幕显示临时热点、随机密码及 `http://192.168.4.1`。
   手机连接该热点，在页面填写初始 2.4 GHz Wi-Fi。设备使用构建时预设的 PA 地址和公开 CA。
3. 连网后，如 PP 显示 8 位配对码，在 PA 配置后台的 AI Passport 页面填写设备名称和
   配对码。码有效期 10 分钟。配对完成后本机拥有独立的持久会话。
4. 后续在 PA 后台维护此设备的云端设置及最多 5 套有序 Wi-Fi。PP 可以同步 PA 设置、
   连接已存网络或设置 Wi-Fi。开机后每分钟至多尝试 3 次，连接后停止搜寻。

### 连接与本地设置

主页随设备状态显示热点信息、八位配对码或连接诊断。短按 OK 打开双列操作菜单，默认选中左上角的「任务消息」。
上、下按从左到右、从上到下的顺序移动，OK 进入选中的入口。长按上键从设置、详情或确认页返回主页。
配对成功或后台重连时，已经打开的本地页面保留当前位置。

| 现场情况 | 设备上的操作 |
| --- | --- |
| 首次配网 | 在主页看热点名、密码和地址，手机提交 Wi-Fi 后回到设备查看配对码 |
| Wi-Fi 已连接，等待校时或 PA 暂不可达 | 打开网络与配对 → 网络状态查看详情。「重试连接」沿用现有身份和已保存的 Wi-Fi，也可以退出设备热点 |
| PA 拒绝身份或接入 | 核对后台设备记录及接入配置。旧配对已撤销时，在提示页按下键，或选择网络与配对 → PA 与维护 → 更换 PA 配对。默认取消，上下键切换后按 OK 确认 |
| 更换 PA 配对 | 设备保存新身份后重启，保留 Wi-Fi、服务地址、CA 和本地偏好。使用新码在 PA 后台配对，进入独立的新会话。旧任务及其提交回执继续归属原会话 |
| 设置 Wi-Fi | 网络与配对 → 设置 Wi-Fi，确认后开启设备热点，用手机填写。提交前可以用「重试连接」返回原有 Wi-Fi |
| 清空设备设置 | 网络与配对 → PA 与维护 → 恢复出厂设置，需要单独确认。此操作会清除本地 Wi-Fi 和配对信息 |

页面名称、父页面和菜单项由 `navigation.c` 声明，`pp_navigation_route` 统一决定按键及画面的归属。维护确认优先，本地页面可在连接状态变化时继续操作。连接状态单独保存，主页与网络详情读取同一份诊断。

8047 的 `/entrances/ai_passport/` 是业务入口，9443 仅分发固件。HTTP/WS 不等 NTP；
只有明确使用 HTTPS/WSS 时才需要有效时间及可信证书。不能跳过证书校验。
**没有 USB 配网、配对文件、证书上传配对或继续听入口。** USB 保留刷写和只读诊断。

## 三个按键

| 操作 | 行为 |
| --- | --- |
| 长按 OK | Wi-Fi 断开且已保存网络时立即重试，正在尝试时忽略。正常对话时保留按下起始声音，长按成立后开始识别，松开即停 |
| 短按 OK | 播报中永久结束本条声音；平时打开菜单，历史浏览时返回最新回复 |
| 双击 OK | 原地切换引导／排队，保存本地选择 |
| 上／下 | 播报准备及播放中调音量；其他时候翻正文、前后聊天记录或菜单项 |
| 长按上约650ms | 从其他页面返回形象主页并停止声音；丢弃未发送输入，已接受任务继续执行 |
| 在空闲主页长按上 | 满 1 秒提示「继续长按将休眠」，满 2 秒立即熄屏。休眠沿用 Wi-Fi 设置，松手仍保持黑屏 |
| 长按下约650ms | 聊天和历史中跳到最新消息，离线时打开最近的可读缓存 |
| 任务详情短按 OK | 返回任务列表；列表、设置及维护菜单有明确返回项 |

开机和深睡唤醒默认停在形象主页；唤醒按键释放后才接受下一次操作。
从其他页面按住上键返回主页后，松开并重新长按才能休眠。
主页上下查看消息；如有待回答问题，先显示问题，按住OK回答。
输入被接收后，状态栏显示「等待回复」和依次点亮的三个圆点。收到回复、进入澄清或请求结束时收起圆点。
双击判定期间只预缓存声音，长按成立前不显示收音状态、不启动云识别。
长按确认时播放短上扬音，松手停录后播放短下落音。两个声音随设备音量调节。
用户已在预录时开口的情况下保留原录音，跳过开始音。音频线程在提示音播放期间丢弃对应的麦克风帧。
空输入只显示形象及“未检测到内容，请重新说。”，不显示错误码或多段解释。

录音达到 60 秒后停止收音并完成转写，**默认丢弃**，明确选择发送才提交。
录音时按可用内存缓冲约 0.64 至 1.28 秒的音频。短时卡顿恢复后继续按顺序上传。
缓冲耗尽时停止收音，连接仍可用时转写连续的已录部分，交给同一个确认菜单。
松手后显示正在上传，上传完成才显示识别中。上传中断或 15 秒内未排空时结束本次录音。
确认菜单另有“查看完整转写”：上下分页，OK 返回确认菜单。设备只保存当前页，全文由 PA
会话模块保留；断线或设备重启后查询同一输入收据，恢复待确认状态，不自动发送。
停播不取消任务，不提供恢复、继续或重播。后台任务不因设备断网或休眠重做。
播报时调节音量，底部状态区显示数值及进度条约1.4秒；连续按键延长显示，停播后隐藏。
该提示复用状态区，不遮住正文，也不会让正文重新翻页。
完整句只有在确认属于回答时才播报；不明确的供应商输出等最终确认，文字仍流式显示。

双列操作菜单下方有返回主页。PA 在线且当前会话有可取消请求时显示「取消当前执行」。

- 任务消息打开原有任务列表。
- 声音与屏幕包含音量和屏幕亮度。亮度以 5 个百分点为步长实时预览，短按 OK 保存；长按上回主页会放弃预览。
- 网络与配对包含网络状态、重试连接、设置 Wi-Fi，以及集中管理同步 PA 设置、更换配对和恢复出厂的「PA 与维护」。
- 「PA 与维护 → 关于设备」一屏显示机型、芯片、闪存、当前固件版本及协议版本，离线可查看，按 OK 返回。
- 电源与待机包含自动休眠、熄屏保持 Wi-Fi 和立即休眠。

各子菜单为单列列表。「返回上级」恢复父菜单原焦点；从主页重新打开菜单时再次选中任务消息。

任务列表及详情采用蓝色标记，与绿色聊天区分。任务详情OK返回列表，长按上直达主页。
返回主页或打开菜单不会取消执行；后台新结果不会抢走正在浏览的页面。
出厂操作只清除此终端私有设置；不删除服务器会话和任务。
默认空闲 2 分钟休眠；收音、识别、前台执行及播放过程中不自动休眠。没有可靠充电检测，
桌面使用时手动选择保持在线。唤醒后先等待按键释放。

「熄屏保持 Wi-Fi」默认打开，是本机设置。熄屏时断开 PA 并暂停业务心跳，
保留已经连上的 Wi-Fi，停用显示和音频。熄屏后热点断开时等按键唤醒再搜寻；
连接还在时直接用它连接 PA。关闭此设置时仍使用原来的深睡。

## 屏幕与内存

- 状态栏电池以填充表示剩余电量，小号数字居中并随背景反色，上下各留出 2 像素。20% 及以下使用红色提示，读不到电量时显示「--」。
- 猫资源预转换为 Flash 中 RGB565+A8，不在 MCU 解码 PNG 或缩放全屏透明层。
- 本机和 PA 后台均可设屏幕亮度 40%–100%（默认 65%）。本机保存的值会跨重启保留，PA 下发新亮度配置时应用新值。正文字号为 16／18，两档字库在 Flash 中，
  按实际字高与可用区域计算完整行数；输入跟随最后几行，回复按页查看，不挤占状态栏或页脚。
- 最近3条已完成消息使用独立Flash缓存，含文字和缩略图，重启后保留。有效数据预算256 KiB，
  不保留流式临时片段；先同步各条开头，再轮流补页。在线浏览不会挤掉最近窗口，离线从最近记录进入。
  单次最多预取96页，长内容可能只覆盖部分；到缺页/边界明确提示联网。
- 支持高清的 PA 按 216×194 图片区域等比缩小原图。设备每次接收并校验最多 8 行
  RGB565，绘制后释放当前块；已绘制像素留在屏幕，最多 64×32 的预览可写入离线缓存。
  连接旧版 PA 时继续显示兼容缩略图。
  原图、完整工具日志和完整会话不会加载到设备。断网不下载未缓存内容。
- 上行 16 kHz、下行 24 kHz、单声道 PCM16；有界音频队列与播放信用窗口。

以上容量是当前实现上限，体验及并发内存仍须以真机验收记录为准。

开发验收顺序为：完成全部功能 → 软件检查及固定SDK构建 → 同一候选集中真机测试。
具体见[集中真机验收](../../../docs/hardware-acceptance.md)，不在每项UI调整后单独刷机验收。

## 编译、刷写与诊断

固定 ESP-IDF 5.5.3、LVGL 9.5.0、ESP32-C3、8 MB Flash、无 PSRAM；依赖见锁文件。

```sh
source /home/macaulish/workspace/pp-firmware/toolchain/activate.sh
cd /home/macaulish/workspace/PersonalAgent/src/assistant_runtime/plugins/ai_passport/firmware/apps/pa_terminal
idf.py -DPP_PA_URL=https://pa.example:8047 -DPP_PA_CA_FILE=/path/to/public-ca.pem build
python ../../tools/package_firmware.py --build build --output build/pa-terminal.zip
```

`PP_PA_URL` 是目标实例的业务根地址，使用系统可信 HTTPS 或显式 HTTP 测试地址时，
可将 `PP_PA_CA_FILE` 设为空。私有 CA 只接受公开 PEM 证书。刷入新固件时保留已有实例设置，
第一次填写 Wi-Fi 或主动重新配网后才采用本次发布的 PA 地址和 CA。

PA终端使用本目录`partitions.csv`：NVS/PHY地址不变，应用分区结束于0x780000，
其后512 KiB为独立缓存分区。首次启用此缓存必须同时更新分区表和应用；仅刷应用不能获得缓存。
发布包不包含缓存或NVS镜像。

生成包中的分段地址以清单为准。常规更新不整片擦除、不写 NVS；不要用合并镜像冒充保留设置。
协议 1 的旧终端不能连接协议 2 服务。旧 `pa_terminal` NVS 数据不会被新程序自动复用；
新格式使用 `pa_terminal_v2`，保留旧空间不代表已有配对已经迁移。首次升级按上述热点流程设置。

USB 串口 115200 下输入 `pp.status`，返回版本、协议、连接状态及内存指标。没有 USB 写配置
或恢复出厂命令。日志与 JSON 共用串口；记录日志不能只查以 `{` 开头的行。

修改猫形象时，使用 `generate_avatar.py --open <PNG> --blink <PNG>` 离线生成原生资源；
源文件摘要、尺寸和生成文件摘要见 `main/assets/avatar.json`。日常构建直接嵌入已生成的原生资源。
