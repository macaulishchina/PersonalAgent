# PA-Terminal 0.2.0

AI Passport 的 PA 交互入口。代码与构建已经接通协议 2；真机验收状态以
[交付清单](../../../docs/terminal-rebuild.md)及[验收记录](../../../docs/acceptance.md)为准。
PPDemo／PPDemo-Zh 仍是独立的硬件体验程序。

## 安装与首次使用

1. 使用现有固件网站安装 PA-Terminal。网页 USB 刷写要求可信 HTTPS；这不表示
   PP 的业务连接也必须使用 HTTPS。使用数据线，选择 USB JTAG/serial 设备。
2. 首次开机未配置网络时，屏幕显示临时热点、随机密码及 `http://192.168.4.1`。
   手机连接该热点，在页面填写初始 2.4 GHz Wi-Fi 和 **PA 业务根地址**，例如
   `http://110.0.0.82:8047`。本地页面不向固件网站上传密码。
3. 连网后，PP 显示 8 位配对码；在 PA 配置后台的 AI Passport 页面填写设备名称和
   配对码。码有效期 10 分钟。配对完成后本机拥有独立的持久会话。
4. 后续在 PA 后台维护此设备的云端设置及最多 5 套有序 Wi-Fi。PP 菜单可以重载配置、
   重试连接和重新配网；每次连接最多按顺序尝试 3 轮，耗尽后等待明确重试。

8047 的 `/entrances/ai_passport/` 是业务入口，9443 仅分发固件。HTTP/WS 不等 NTP；
只有明确使用 HTTPS/WSS 时才需要有效时间及可信证书。不能跳过证书校验。
**没有 USB 配网、配对文件、证书上传配对或继续听入口。** USB 保留刷写和只读诊断。

## 三个按键

| 操作 | 行为 |
| --- | --- |
| 长按 OK | 保留按下起始声音；长按成立后开识别，松开立即停止收音 |
| 短按 OK | 播报中永久结束本条声音；平时打开菜单，历史浏览时返回最新回复 |
| 双击 OK | 原地切换引导／排队，保存本地选择 |
| 上／下 | 播报准备及播放中调音量；其他时候翻正文、前后聊天记录或菜单项 |
| 长按上约650ms | 返回形象主页并停止声音；丢弃未发送输入，已接受任务继续执行 |
| 任务详情短按 OK | 返回任务列表；列表、设置及维护菜单有明确返回项 |

开机和深睡唤醒默认停在形象主页；唤醒按键释放后才接受下一次操作。
主页上下查看消息；如有待回答问题，先显示问题，按住OK回答。
双击判定期间只预缓存声音，长按成立前不显示收音状态、不启动云识别。
空输入只显示形象及“未检测到内容，请重新说。”，不显示错误码或多段解释。

录音达到 60 秒后停止收音并完成转写，**默认丢弃**，明确选择发送才提交。
确认菜单另有“查看完整转写”：上下分页，OK 返回确认菜单。设备只保存当前页，全文由 PA
会话模块保留；断线或设备重启后查询同一输入收据，恢复待确认状态，不自动发送。
停播不取消任务，不提供恢复、继续或重播。后台任务不因设备断网或休眠重做。
播报时调节音量，底部状态区显示数值及进度条约1.4秒；连续按键延长显示，停播后隐藏。
该提示复用状态区，不遮住正文，也不会让正文重新翻页。
完整句只有在确认属于回答时才播报；不明确的供应商输出等最终确认，文字仍流式显示。

菜单每层最多5项，顺序如下：

- 操作菜单：任务消息、音量、取消当前执行、设置、返回主页。
- 设置：保持在线、网络状态、休眠、设备维护、返回上级。
- 设备维护：重载配置、重试连接、重新配网、恢复出厂、返回上级。

任务列表及详情采用蓝色标记，与绿色聊天区分。任务详情OK返回列表，长按上直达主页。
返回主页或打开菜单不会取消执行；后台新结果不会抢走正在浏览的页面。
出厂操作只清除此终端私有设置；不删除服务器会话和任务。
默认空闲 2 分钟休眠；收音、识别、前台执行及播放过程中不自动休眠。没有可靠充电检测，
桌面使用时手动选择保持在线。唤醒后先等待按键释放。

## 屏幕与内存

- 状态栏显示时间、音量、Wi-Fi 和电池内数字；电量读取失败显示未知，不伪造百分比。
- 猫资源预转换为 Flash 中 RGB565+A8，不在 MCU 解码 PNG 或缩放全屏透明层。
- 后台可设屏幕亮度40—100（默认65），正文字号16／18。两档字库在Flash中，
  按实际字高与可用区域计算完整行数；输入跟随最后几行，回复按页查看，不挤占状态栏或页脚。
- 最近3条已完成消息使用独立Flash缓存，含文字和缩略图，重启后保留。有效数据预算256 KiB，
  不保留流式临时片段；先同步各条开头，再轮流补页。在线浏览不会挤掉最近窗口，离线从最近记录进入。
  单次最多预取96页，长内容可能只覆盖部分；到缺页/边界明确提示联网。
- 图片仅保留一张 RGB565 缩略图，按实时内存余量选择尺寸，分块校验顺序和 SHA256。
  原图、完整工具日志和完整会话不会加载到设备。断网不下载未缓存内容。
- 上行 16 kHz、下行 24 kHz、单声道 PCM16；有界音频队列与播放信用窗口。

以上容量是当前实现上限，体验及并发内存仍须以真机验收记录为准。

开发验收顺序为：完成全部功能 → 软件检查及固定SDK构建 → 同一候选集中真机测试。
具体见[集中真机验收](../../../docs/hardware-acceptance.md)，不在每项UI调整后单独刷机验收。

## 编译、刷写与诊断

固定 ESP-IDF 5.5.3、LVGL 9.5.0、ESP32-C3、8 MB Flash、无 PSRAM；依赖见锁文件。

```sh
source /home/macaulish/workspace/esp32-toolchain/activate.sh
cd /home/macaulish/workspace/dell-voice-assistant/src/assistant_runtime/plugins/ai_passport/firmware/apps/pa_terminal
idf.py build
python ../../tools/package_firmware.py --build build --output build/pa-terminal-0.2.0.zip
```

PA终端使用本目录`partitions.csv`：NVS/PHY地址不变，应用分区结束于0x780000，
其后512 KiB为独立缓存分区。首次启用此缓存必须同时更新分区表和应用；仅刷应用不能获得缓存。
发布包不包含缓存或NVS镜像。

生成包中的分段地址以清单为准。常规更新不整片擦除、不写 NVS；不要用合并镜像冒充保留设置。
协议 1 的旧终端不能连接协议 2 服务。旧 `pa_terminal` NVS 数据不会被新程序自动复用；
新格式使用 `pa_terminal_v2`，保留旧空间不代表已有配对已经迁移。首次升级按上述热点流程设置。

USB 串口 115200 下输入 `pp.status`，返回版本、协议、连接状态及内存指标。没有 USB 写配置
或恢复出厂命令。日志与 JSON 共用串口；记录日志不能只查以 `{` 开头的行。

修改猫形象时，使用 `generate_avatar.py --open <PNG> --blink <PNG>` 离线生成原生资源；
源文件摘要、尺寸和生成文件摘要见 `main/assets/avatar.json`。日常构建直接使用这些资源，
不依赖 Demo 仓库、PNG 解码器或图片转换服务。
