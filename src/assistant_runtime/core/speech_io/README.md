# 流式语音 I/O

可选核心插件，不依赖本地声卡、唤醒模块或个人助手宿主。由同一公共
PluginContext 装配；核心身份不要求使用整个宿主。默认不开启。

`SpeechRequest` 接受识别或合成操作，识别返回有序 PCM 输入流，合成返回
有界输出迭代器。仅最终转写可由入口提交对话；本模块不运行 Agent。
`RecognitionRequest` / `SynthesisRequest` 是分别可替换的供应商契约。
每一种请求类型只启用一个提供方；缺少提供方时明确不可用，不自动回退。

输入为 16 kHz 单声道 PCM16，序号从零连续递增；重复、缺帧、奇数字节、
超量、超时及取消均关闭本次输入，不执行残缺指令。输出为 24 kHz 单声道 PCM16。
配置以同目录 configuration.json 为唯一默认值与基础校验来源。
默认同时两条流、单次收音 60 秒；关闭时清理所有活动流。

供应商适配必须在付费派发前通过 ai_usage，不能自建费用账本或自动回退。
原始音频只保留在有界内存，不保存录音。短回复直接朗读，长回复按完整句段
播报最多 200 字；超过限制且无句段边界时要求查看文字，不能伪称已朗读全文。
