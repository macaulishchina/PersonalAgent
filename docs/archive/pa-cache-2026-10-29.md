# PA-CACHE 实现反馈

日期：2026-10-29。适用于 PA 0.4.1，公共 API 仍为 2。

- 无新增公共参数。继续使用原有 `ExecutionRequest` 的 text、inputs、tools、skills。
- 公共独立执行的系统说明使用 `.`（本轮 scratch）和 `../artifacts`。Pi 发给模型的 cwd 说明同步使用相对路径；工具真实 cwd、执行目录、会话、授权和用量身份继续独立。
- 显式白名单包含不超过 `min(4, max_loaded_tools)` 个 MCP 工具时，借助 Pi 的 direct-server 就绪机制准备声明。声明 JSON 总计超过 16 KiB、工具缺失或隐藏时，继续延迟发现。权限检查和审批不变，预载不执行工具。
- 大工具集、隐式目录、普通对话、后台任务和受控上下文保持各自原有提示策略。不创建跨执行历史或缓存亲和身份。当前 Pi 系统提示构造会注入 cwd，未发现实时日期；本地验收比较了实际供应商请求。
- `tools.updated` 继续报告声明大小及工具列表；脱敏 discovery 日志记录 preloaded / preload_deferred。缓存预热和自动付费重试保持关闭。
- 缓存读／写的正数计数沿用供应商 SDK 数据。当前 SDK 无法区分“未报告”和默认零，因此零／缺失显示为未知；总输入／输出计量不变，不把价格未知当免费。

## 针对性验证

88 项执行、消息回执、工具发现、模型账号与用量测试通过。实际 Pi + 本地合成供应商验证：两次独立执行的工具和输入完全一致，各自正确写入独立产物目录，保留不同会话身份与请求去重。两轮各 2 次请求，无额外预热请求；小白名单首次已声明，后续声明变化为 0，超量／超大声明回到延迟发现，越权工具未执行。合成请求不代表真实 token 或价格收益。

Windows Server 本机运行；Linux 未做本轮原生运行验收。公共 API、请求去重、unknown、不重放和产物归属的相关回归通过。

真实连接使用合成文本、空工具集，每次输出上限 512 tokens。两轮中，首轮因测试采集器错误未保留明细，未重放该执行。另一轮完成：总输入 2,351 tokens，缓存读 2,176，未缓存输入 175，输出 23；缓存写与价格未知。完整首次／后续对照未完成，不能据此宣称跨执行收益比例或所有供应商都命中。
