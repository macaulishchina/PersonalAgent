## 真实模型

最终隔离实例使用已有 API 路由与内存凭据，源模型 `gpt-6.1-sol`；目标分别为 `gpt-6.1-sol / low`、`gpt-6-luna / medium`。两个任务均从同一快照正确取得随机源事实及 5,982 字符追加背景中的随机事实，重启后回执及任务结果保持。

最终验收实际 3 次模型调用，脚本上限 4 次、单次输出上限 512 token，并限制输入／输出 token 和隐式重试。先前一轮因模型目录容量预留超出验收输入预算，被用量准入拦在派发前；证据保留。修正验收实例声明容量后通过，未更改生产预算。

末轮目标用量分别为输入 2,148／2,140 token，输出 22／60 token；源输入 1,724、输出 5 token。没有配置价格表，金额为未知，不能把零估算当作免费或金额上限。缓存读取遥测为未知，供应商上报的缓存写入值已单独保留，不由此前缀测量推断命中率。
