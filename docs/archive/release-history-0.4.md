# 0.4 发布历史

本页归集原发布流程中的版本变更说明，保留当时的描述，不构成当前部署或验收结论。这里不是完整版本清单；当前流程见[发布与切换](../development/release.md)，当前接口以模块手册为准。

`0.4.6` 统一工具可调用性、可见定义与结果证据，并补齐插件工具声明校验。公共插件 API 仍为 2，数据格式仍为 1；现有满足兼容范围的插件无需批量升级。Web 的工具状态呈现随 `1.2.1` 发布；独立示例 `1.1.1` 演示本版新增错误契约，最低核心版本为 `0.4.6`。修改版本号不代表已经提交、安装或上线。

全部 28 个内置插件的能力、资源、配置和工具契约已按统一要求复核。此次适配涉及 `media 1.1.1`、`decisions 1.2.1`、`search 1.1.1`、`hid_buttons 1.1.1`；其余未修改的扩展保持原发布版本。HID 配置描述归回插件，实例中的 `hid_buttons` 文件字段不变。健康状态修正和参数契约不触发旧任务重放或数据重置。

`0.4.7` 修复任务准备失败、未知执行核对与停止收尾，分离任务授权范围与显式互斥锁，并在任务模型从配置移除时于派发前重新选型。API 仍为 2，数据格式仍为 1；新增任务生命周期审计表为增量变更，历史未知占用不自动清除。网页扩展更新至 `1.2.2`，要求内核至少 `0.4.7`；其它扩展原有兼容范围继续适用。

`0.4.10` 统一收到的工具与最终结果留存、授权分页读取、保留期限与容量管理；Web `1.2.4` 增加完整结果读取。API 仍为 2，数据格式仍为 1，新增索引与可选结果引用采用增量结构，不重置历史执行。模型策略、重试和输出限制保持不变。

`0.4.11` / Web `1.2.5` 统一聊天正文的完整／节选呈现，去除普通回复的重复结果查看器；连续执行过程在整轮结束后默认折叠，保留答复、图片和手动查看入口。长回复使用对应消息的范围原位读取。API 仍为 2，数据格式仍为 1；新增呈现元数据不改变工具权限或任务执行策略。

`0.4.12` / Media `1.1.2` / Web `1.2.6` 修复夸克分享虚拟根的归属校验，保留普通目录及分享子目录的严格校验和转存前成员／令牌复核。已知媒体和结果读取错误通过 IPC/MCP 保留具体原因；可信只读调用采用可配置的尝试上限，未知写操作及第三方 MCP 提示不获得重放许可。API 仍为 2，数据格式仍为 1，不自动重新提交历史任务。

`0.4.13` / Web `1.2.7` 修复 Pi 接单确认被内部 30／60 秒控制超时提前截断的问题，主对话、后台任务及独立执行统一使用配置的模型／压缩期限，显式调用期限仍有效。提交异常保存可见答复；压缩期间显示“正在整理上下文…”，刷新可恢复，结束或断连清除。API 仍为 2，数据格式仍为 1，不自动重发未知请求。

`0.4.14` 增加可选公开模型路由约束、模型默认深度、创建回执核对及外观资源，优化已有任务查询。API 2、data_format 1 及旧插件默认行为保持；没有插件大版本升级。接入及证据见 [公开模型路由](../guides/model-routes.md)和[交付说明](pa-lite-0.4.14.md)。本次源码交付不部署在用实例。

`0.4.15` 扩充离线头像库为 30 个提供商品牌、40 个通用头像及默认头像，增加可搜索图墙和内置资源公开读取。旧 builtin 引用、自定义 PNG 接口、API 2 与 data_format 1 保持；未部署在用实例。

`0.4.16` 修复等待澄清任务的取消：Pi 输入工具传递取消信号，并提供确定的本地取消回执；同步清理原生问题关联、执行问题与任务问题快照。真实外部操作结果未知时仍保留 unknown，不新增接口、不重跑任务；API 2、data_format 1 与扩展版本不变。定向验收与复验入口见[修复说明](cancel-waiting-0.4.16.md)。本次仅交付修复候选，不部署。


`0.4.17` 新增可选的会话上下文快照及独立任务背景。未传 `spec.context` 的任务沿用原路径；API 仍为 2，数据格式仍为 1，快照与任务关联采用新增表，不重置历史或重派任务。协议、保留和接入示例见[任务上下文快照](../guides/task-context-snapshots.md)。

`0.4.18` / Web `1.2.8` 分开说明正文留存及图片登记的实际状态；纯文字结果不再声称已交付图片。网页按回复轮次统一展示媒体，执行中可见，最终位于文字下方，按登记 ID 去重，迟到媒体及刷新沿用同一归属。工具证据、原文、任务报告和授权边界保留；不搬移文件、不重做工具。API 2、数据格式 1 不变。

`0.4.19` 收紧模型及连接编辑器的个性配置布局，统一分组对齐；头像只保留可视化选择入口，上传与恢复默认集中展示，适配窄屏。配置草稿、头像存储及 API 2／数据格式 1 保持兼容。

`0.4.20` / Web `1.2.9` 将已保存的公开名称、说明和头像用于配置列表、模型选择器及聊天显示；reload 重新读取已生效目录，未单独指定的模型头像继承连接。聊天头像通过原有模型公共接口和聊天认证读取；图片失效时显示默认图标。登记 ID、路由修订、模型调用、API 2 及数据格式 1 保持兼容。

`0.4.21` 修正自定义 Responses 连接的空助手文本重放：仅在发送副本中忽略零长度文本块，避免工具调用和返回之间生成额外空助手消息。实际文字、工具 ID、结果、快照及持久历史均保留；普通对话和快照任务共用修复。API 2、数据格式 1 及插件主版本不变，不自动重试或重派既有失败执行。[影响、验收及原故障归因限制](context-tools-protocol-0.4.21.md)。

`0.4.22` 为新产生的任务澄清提问增加可验证的持久等待检查点。恢复等待不调用模型；
明确回答后保留原任务、执行、轮次、模型和共享用量继续。未知操作、损坏或旧历史不猜测恢复。
任务补充接口新增可选的问题／答案身份和既有执行回执；旧插件调用、API 2、数据格式 1
保持兼容，不自动重派既有未知执行。详见[任务恢复契约](../../src/assistant_runtime/core/tasks/README.md#等待澄清后的重启)。

另见[0.4.8 的会话与任务工具记录](release-0.4.8.md)。
