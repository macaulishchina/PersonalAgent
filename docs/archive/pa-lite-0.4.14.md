# PA-L v2 交付与验收记录

日期：2026-11-04。源码基线已 rebase 到 89ff72a（0.4.13）；本次兼容候选 0.4.14。
仅交付源码与验证，不部署、不升级或重启在用实例。最终提交见本文件所属提交。

## 范围

| 清单 | 交付映射 |
| --- | --- |
| L1 | ModelRequest(catalog)、同源任务模型路由、会话可选执行回执、任务 execution_facts、原生执行持久路由 |
| L2 | 可选 expected_model 条件、接受/最终派发校验、严格任务拒绝替换及模型交接 |
| L3 | 显式 effort_mode=model_default，冻结模型默认含 auto；旧省略/auto 规则保留 |
| L4 | TaskRequest(receipt)，按原 request_id 只读核对，可比较原始请求指纹 |
| L5 | 复用可信工具上下文、共享额度、通知与结果；无新来源协议、无全局子任务禁令 |
| G1 | provider/entry 外观配置、内置字母图标、规范化上传、版本资源事务及公开受控读取 |
| G2 | 优化原分页/known、最近/活动执行及 execution_info；无平行 summaries API |

接口示例、参数、错误、权限边界及限制见 [接入指南](../guides/model-routes.md)。KFC 业务、页面、引用、作者快照和端到端联调仍由 KFC 负责。

## 兼容与迁移

公共 API 2、data_format 1 不变；没有旧接口改名、强制新参数、配置重置或插件大版本升级。
原模型/会话/任务默认规则、通知、子任务和安全请求重试保留。新调用应声明核心版本至少 0.4.14，旧插件不为此批量修改兼容范围。
增量新增 conversation_execution 表；任务轮次和 Pi 元数据新增可选事实字段。旧历史不回填猜测值、不重放未知操作。
presentation 可选，旧配置不需修改；头像是配置资源，进入原有快照、事务、冻结读取及恢复流程。
升级仍应按 PA 规范备份并验证；运行态降级不能仅 git checkout，需匹配代码/依赖/数据。本文不授权实际部署。

## 已完成证据

- 新定向测试覆盖：路由区分/改绑/停用、展示与密钥轮换稳定性、旧 auto 规则、新默认冻结、固定策略冲突、严格升级拒绝、创建回执一致性、队列幂等、最终拒绝释放容量。
- 真实 Windows Pi 1.4.0 + 本地合成供应商：双模型并发、auto/high 深度、历史路由读取和派发前拒绝。
- 独立真实企业兼容网关：gpt-6-luna 主会话委派 deepseek-v4.1-flash；直接任务保留默认 auto，委派具体 low，验证共享工作额度、重复创建幂等、只读创建关联、结果引用和关闭完成通知。全部使用合成文本；未验证网关背后的底层版本。
- 真实供应商脚本 scripts/verify_model_routes.py 使用临时实例、独立账本、最多每工作 4 次调用、关闭自动重试和 1024 输出上限，不读取原会话历史、不写原凭据。
- Edge 管理页验收：名称/说明、上传首帧规范化、草稿不落盘、PNG 实际解码、保存后受控读取与 ETag、恢复默认及取消、原模型选择器回归。
- 配置资源测试覆盖缺失/损坏引用拒绝、非法格式/路径、元数据清除、磁盘失败回滚及凭据保持。

私有原始证据位于 state/acceptance/pa-lite/；不提交实例凭据或配置。源码测试证明宿主语义，真实网关验收仅证明上述模型与参数路线。
创建丢响应的只读恢复由持久回执/幂等测试覆盖；真实供应商验收核对回执与重复提交，不声称实际注入了远端网络断连。
