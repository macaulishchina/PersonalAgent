# CLI 使用

前提：已安装应用，并配置好模型。命令入口是 `pa`。

## 选择实例并聊天

```text
pa use <已有实例目录>
pa
```

实例目录是保存 `management.toml`、`config/`、凭据和历史数据的目录，不是源代码目录。`pa use` 只记住选择，不创建实例、不启动进程、不修改插件配置。

以后直接运行 `pa`。临时使用其他配置可执行 `pa --config <配置文件> chat`，不会改变记住的实例。已有会话可用 `pa chat --session <ID>` 打开。

## 聊天命令

| 操作 | 命令 |
| --- | --- |
| 普通消息 | 直接输入文本，同一会话按顺序排队 |
| 新建会话 | `/new` |
| 查看／切换会话 | `/sessions`、`/switch <ID>` |
| 查看历史 | `/history` |
| 查看等待和活跃请求 | `/queue` |
| 补充当前执行 | `/supplement <内容>` |
| 回答当前澄清问题 | `/answer <问题ID> <内容>` |
| 取消当前执行 | `/cancel` |
| 取消指定请求，包括排队消息 | `/cancel <请求ID>` |
| 帮助／离开 | `/help`、`/exit` |

Ctrl+C 清除当前输入；停止执行必须显式使用 `/cancel`。退出、终端断开、切换会话都不会取消已接收的工作。附件结果以引用和获取方式显示，首版 CLI 以文本输入为主。

## 会话与结果

首次连接创建独立 CLI 会话，之后恢复该操作者上次选择。网页保持自己的主会话；其他终端切换会话不会强制改变当前终端。

同会话共享历史和输入队列。不同会话可并行，但共用执行并发上限和用量保护。补充、回答与取消针对指定轮次；任务报告投递回创建任务的原会话。

重启恢复历史和绑定。尚未派发的输入标为中断，结果无法确认的执行标为未知，都不会自动重做。

## CLI 与后台的关系

`pa` 连接已有实例：运行中则直接连接；未运行时启动归属匹配的已安装系统服务，或启动脱离终端的管理进程。它不会创建实例、安装系统服务或申请管理员权限。

```sh
pa status
pa stop
pa restart
```

`pa stop` 停止整个实例后台，`/cancel` 只取消聊天中的一轮工作。模型未配置时提供配置指引，不发送模型请求。

服务安装、日志和故障处理见[日常维护](operations.md)。入口选择优先级和实现契约见[CLI 模块](../../src/assistant_runtime/core/cli/README.md)。

## 版本与升级检查

`pa --version` 显示内核版本；`pa version` 输出包含协议及数据格式的版本信息，两者都不要求已创建实例。`pa plugins` 展示所选实例的全部插件版本、启用状态和兼容原因。`pa upgrade-check <目标wheel>` 离线检查候选发布包，可追加 `--plugin-wheel <独立插件wheel>`。兼容检查通过不执行安装；完整升级流程见[日常维护](operations.md#备份和升级)。
