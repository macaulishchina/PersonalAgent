# 实例技能

私有设备操作经验放到 `<root>/config/skills/<技能名>/SKILL.md`，在总入口显式选择：

```toml
instance_skills = ["living-room-tv"]
```

技能名使用小写字母、数字和连字符，以字母开头；最多 32 个，不允许重名或覆盖已启用的内置技能。
每个技能采用 `SKILL.md` 的 name/description 前置信息及操作正文，配套资料可放 `references/`。
配置重启生效；未选择的目录不会自动加载，选择了但文件不存在则启动报错。

这里只放操作方法和带来源的设备经验。长期用户事实继续通过已有 memory 能力维护，
密钥使用私有凭据引用。通用操作技能属于相应业务插件并随安装包交付；
Coding AI 的技能、项目规则和开发记录属于本机 `.agents/`，不会传给助手。
本模板不包含家庭设备身份、地址、历史测试记录或真实凭据。
